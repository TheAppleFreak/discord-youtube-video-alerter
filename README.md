# discord-youtube-video-alerter
A small bot to post new videos to a Discord channel via webhooks.

## Setup

If you're setting this up, you'll need a few things.

1. [Download and install Node.js](https://nodejs.org/en/download) (if you don't know what to get, jut hit the "Windows Installer (.msi)" button on the page). This should work with basically any Node version out there.
2. Clone or download this repository locally. You can do so with the green "<> Code" button at the top right.
3. Run `npm install` to install dependencies. Alternatively, if you don't feel comfortable with the command line or terminal, double click install.bat to run the command for you.
4. Rename `.env.example` to `.env`, then fill out each line with the appropriate information. 
5. Run the application with `npm start`, or double click `start.bat` to run it instead. You can close it out by hitting `Ctrl-C` in the terminal window that appears.
